# Conversor de skins · Actions & Stuff Expresiones

Convierte una skin de Minecraft (64x64, 128x128 o 256x256) en una skin compatible
con el addon
*Actions & Stuff — Expresiones* de Oreville Studios: escribe la cara de parpadeo,
la cara trasera y los cubos de ojos y cejas en las posiciones de la plantilla oficial.

**Se abre en:** [`index.html`](index.html) (o la raíz del sitio).

Todo ocurre en tu ordenador: la imagen nunca se sube a ningún sitio.

- `conversor_actions_stuff_expresiones_FINAL.html` — la herramienta (un solo archivo).
- `ENTREGA_copiar_o_descargar.html` — página con el código para copiar o descargar.
- `conversor_AS_expresiones_TODO.zip` — todo junto.

Las descargas oficiales de Oreville (pack de skins y plantilla de Blockbench) están en
sus propias páginas: <https://orevillestudios.com/actions-&-stuff/expressions/download>.

Este proyecto no está afiliado a Oreville Studios ni a Mojang.
